WiTV

打开电视，就在播。

WiTV 是给 Android TV 和电视盒子用的开源直播播放器。它播放你自己的 M3U 直播源：开机就在播，用遥控器换台，设置在手机上完成。

上面这台电视可以直接操作：点一下画面，再按方向键。

沙发上的人什么都不用设置

看电视的人

家里的老人和孩子只需要方向键、确认和返回。开机直接进直播，换台、找分组、按数字键跳台，字号按三米外能看清来定。

管设备的人

直播源、节目单、组播代理都在手机或电脑浏览器里配置。电视屏幕上显示二维码和局域网地址，不用拿遥控器打字。

三步装好

  1. 把 APK 装到盒子上

    支持 Android 6.0 及以上的电视和盒子，在斐讯 N1（Android 7.1）上开发和测试。

  2. 用手机扫电视上的二维码

    第一次打开时，电视上会显示管理页的二维码和地址（端口 9979）。手机和盒子在同一个局域网里就能打开。

  3. 添加你的 M3U 地址

    在管理页里填上直播源地址，电视那边会自动加载频道并开始播放。

它能做什么

源不稳
一个频道，多个播放地址同名频道的地址自动合并。播放失败或超时会按顺序换下一个，卡住了会自己重连，并在屏幕上告诉你发生了什么。
换台
分组、频道、今日节目单三栏菜单为遥控器设计的三栏菜单，当前节目原位高亮。上下键直接换台，数字键跳到指定频道，常看的频道可以收藏。
节目单
XMLTV 节目预告可以用直播源里自带的 EPG 地址，也可以换成自己的，在管理页里一个开关切换，节目单会自动刷新。
组播
UDP / RTP 组播直连或走 udpxy支持运营商 IPTV 组播频道，带 RTP 剥头与乱序重排；收不到组播时可以配置 udpxy 转成 HTTP 单播。
老盒子
硬解优先，FFmpeg 兜底内置 FFmpeg 软解，补上盒子硬解常缺的 MPEG-2 视频与 MP2 / AC3 音频。可以选择硬解优先、软解优先或仅硬解。
开机
可以当桌面用设为默认桌面后，开机、按主页键都直接进直播。返回键里的「切换应用」随时能打开其他应用或换回原来的桌面。
外观
两套主题，中英文界面「标准」是深色面板加蓝色焦点，「电视台包装」是演播室深蓝加白色字幕条。首屏的电视可以直接切换看看。

遥控器怎么按

确认打开频道菜单；停留一会儿没有操作会自动收起
上 / 下上一个 / 下一个频道（方向可以在设置里反过来）
数字键输入频道号直接跳转
信息键显示 / 隐藏节目与信号信息
菜单键打开设置
返回关闭菜单；在播放时按下可以去设置、切换应用或退出

下载

从 GitHub Releases 下载最新的 APK，用 U 盘、adb 或盒子自带的文件管理器安装。WiTV 使用 MIT 协议开源，没有账号，也不联网上报任何数据。
